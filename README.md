# Welcome to Food Xpress

Food Xpress is a responsive food ordering website built with HTML, CSS, Bootstrap 4, and JavaScript.
It allows users to browse meals, place orders, and send them directly via WhatsApp — no backend or database needed.

This project is perfect for food vendors, restaurants, or any business that takes orders through WhatsApp.

Features

✅ Fully responsive layout using Bootstrap 4

📱 WhatsApp ordering integration

🍕 Editable menu and categories

🛒 Add-to-cart–style selection (WhatsApp message includes selected items)

💬 Instant message send via WhatsApp API

⚙️ Simple setup — no backend or database

🧩 Easily customizable for any business

How It Works

User visits the website and browses the available food or products.

They click “Order via WhatsApp.”

The site automatically opens WhatsApp with the order details and total ready to send.

The seller receives the message directly on their WhatsApp number.

You can easily modify Food Xpress for other WhatsApp-based businesses such as:

🛍️ Online stores & boutiques

☕ Cafés or snack shops

🍰 Bakeries & pastry shops

📦 Delivery or logistics services

To change the business type:

Edit menu items and texts in index.html

Update your WhatsApp number in the order button link

Replace images in the img/ folder

Adjust styles in style.css
